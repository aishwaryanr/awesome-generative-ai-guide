# Jev Explained in 12 mins (Without the Hype)

[Watch on YouTube](https://www.youtube.com/watch?v=OsPma0BWq9c) · 2026-09-24

## In this video

- **What Jev is, and how it differs from a regular LLM** (00:42): LLMs generate text token by token, while Jev belongs to a class Typesafe calls System One models, built to make fast, structured decisions that software can act on directly
- **The 3 things it can do** (01:43): choice (pick 1 option from a fixed list), score (rate something on a scale), and Noul (the probability that a statement is true)
- **How it compares to a traditional classifier** (02:33): why a constrained output makes it fast and cheap, and why you can define a new decision schema without retraining
- **Real use cases people are building** (04:01): browser automation that books a flight in about 8 seconds, and predictive spreadsheets that tag sentiment and urgency in milliseconds, from the Made with Jev gallery
- **Where it breaks down** (06:08): arithmetic, counting, date comparison, multi-step reasoning, and anything that needs actual generation, such as a coding agent or drafting email replies
- **Why the future looks like LLMs and Jev working together** (07:54): use Jev for bounded decisions like routing, relevance, and guardrails, and keep LLMs for planning, reasoning, and generation
- **Jev and AI evals** (08:36): how the AI slop detector breaks a judgment into categories and scores each one, and why a constrained judge is cheaper and faster
- **Set up your Jev account** (11:10): create an account, get an API key, and use the agent prompt and skill file that scan your codebase for places to use Jev
